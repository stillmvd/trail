# Quickstart: проверка раздела «Сводка»

## Подготовка

- `cd desktop && pnpm install`; установленный Trail закрыть через трей (single instance) или dev с `--config`
  и другим `identifier` (память `tauri-ui-check-without-browser`).
- `pnpm tauri dev`. Ключ OpenRouter — Настройки → «Картинки» или «Сводка» (один ключ).

## Автопроверки

- `npx tsc --noEmit` — типы.
- `node scripts/digest-selftest.ts` — дедуп, окно свежести, сверка индекса по эху, `trimVerdict`, `topic`/`near`.
- `cargo check` (из `src-tauri`, не при живом `pnpm tauri dev`) — команды превью.
- `pnpm run check` — всё вместе перед релизом.

## Сценарии (по user stories spec.md)

1. **Первый запуск (US6)**: на копии БД без digest-таблиц открыть «Сводку» → источники и интересы как в
   `sources.json` Cairn; `SELECT count(*) FROM digest_items WHERE imported = 1` = 3000; перезапуск не дублирует.
2. **Ручной сбор (US1)**: «Собрать сейчас» → ≤ 2 мин; карточки по темам, тост «Сводка готова, N материалов»,
   точка на пункте «Сводка». Группы — по меткам интересов, «Любопытное» последней. Повторное «Собрать сейчас»
   без вопросов дописывает новые материалы группой «добавлено в ЧЧ:ММ», «Было близко» обновляется; если
   сводка была просмотрена и добавилось ≥ 1 — точка возвращается.
3. **Плановый сбор, догон и повтор (US1)**: время сбора = через 2 минуты, свернуть в трей → сводка без окон;
   удалить сегодняшнюю, закрыть Trail, поставить время в прошлом, запустить → сводка собирается при старте;
   второй не появляется. Отключить сеть до времени сбора → 3 попытки с шагом ~15 мин (`digest_attempts_count`
   растёт и не сбрасывается перезапуском), затем тишина; тоста об ошибке нет.
4. **Чтение (US2)**: j/k по карточкам, Enter открывает браузер, карточка становится просмотренной;
   «Было близко: N» раскрывается в заголовки. Карточка без картинки — заглушка.
5. **Обучение (US3)**: лайк/дизлайк переключаются и снимаются; «Больше не показывать этот домен» →
   следующий сбор без домена; в запросе (лог dev-консоли) — блоки «брал/отклонял».
6. **Архив (US4)**: отметить все карточки → сводка «просмотрена», точка гаснет; звезда → материал в
   «Сохранённом»; поиск раздела находит материалы прошлых сводок; Ctrl+F в другом режиме их не показывает.
7. **Настройки и здоровье (US5)**: добавить ленту с битым адресом → на панели здоровья ошибка, сводка
   собрана из остальных; без ключа — понятная причина вместо сводки.
8. **Сбои**: отключить сеть → сводки нет, причина в разделе, без тоста; включить → «Собрать сейчас» работает.
9. **Трей**: пункт «Сводка» открывает окно в разделе; клик по тосту — тоже.
